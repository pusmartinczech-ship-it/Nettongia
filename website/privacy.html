PRIVACY POLICY / ZÁSADY SOUKROMÍ

Your documents remain local.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Application data

Nettongia PDF Editor processes PDF content, text recognition and document changes locally on the user's computer. It does not automatically upload documents, document text, metadata, file names, paths or passwords.

Diagnostics

The application keeps a bounded local operation log without document content. An anonymized diagnostic ZIP is created only when the user explicitly requests it, shows a preview before export, and is not transmitted automatically. Raw crash logs are never included.

Website

This website does not use advertising, tracking pixels or visitor profiles. It stores only aggregate visit and download-start totals; no IP address, cookie, account or other visitor identifier is written to the counter store. A visit is submitted once per browser session. Cloudflare may process standard network and security data required to deliver the website under its own privacy terms.

Support contact

Support requests can be sent to support@nettongia.com. Email messages are processed by the configured mail provider and contain only the information that the sender chooses to include.

External actions

Following a download, GitHub or source-code link is an explicit request to connect to that external service. Its privacy terms apply there.

Česky

Nettongia PDF Editor zpracovává obsah PDF, OCR a změny dokumentů lokálně. Automaticky neodesílá dokumenty, jejich text, metadata, názvy, cesty ani hesla. Diagnostický ZIP vznikne pouze na výslovnou žádost uživatele, před exportem zobrazí náhled a sám se nikam neodesílá. Požadavky na podporu lze zasílat na support@nettongia.com. Web nepoužívá reklamu, sledovací pixely ani profily návštěvníků. Ukládá pouze souhrnný počet návštěv a zahájených stažení bez IP adres, cookies, účtů nebo jiných identifikátorů.
