PRACTICAL GUIDE

How to edit a PDF offline on Windows

Nettongia PDF Editor processes documents on your computer. Opening, editing, OCR and saving do not require uploading the PDF to a web service.

1. Download and start the portable editor

Download the verified portable ZIP from the official Nettongia page, compare its published SHA-256 value, extract the archive to a normal folder and run NettongiaPDFEditor.exe. Version 0.19.0 is currently an unsigned public beta, so Windows can display an Unknown publisher warning. Do not disable SmartScreen or antivirus protection.

2. Edit text, images and visual objects

Open a PDF and select an existing text object to edit or remove it. You can also create movable, resizable text boxes. Images can be inserted, moved, resized or removed. Right-clicking an object opens the actions that are valid for that object, helping avoid accidental changes elsewhere on the page.

3. Reorder, rotate or delete PDF pages

Use the thumbnail panel on the left to select and rearrange pages. Pages can be rotated left or right without rasterizing their contents. Press Delete over the selected thumbnail, or use its context menu, to remove a page. Page operations participate in Undo and Redo.

4. Make scanned PDFs searchable with offline OCR

For image-only pages, run OCR for the current page or the whole document. Czech, Slovak, Polish, German and English recognition data is included in the portable package, so no separate Tesseract installation or model download is needed. Recognition accuracy depends on scan resolution, contrast, rotation and the selected language.

5. Protect the original with Save a copy

Use Save a copy when the source document must remain untouched. This command always requests a different destination and never overwrites the open source file. Keep the original for archival, certified or signed documents and review the compatibility indicator before saving documents that contain forms, signatures or unusual PDF structures.

What stays local?

Document contents, file names, paths, OCR text and PDF metadata are not automatically sent to Nettongia. The optional diagnostic export is created locally only after confirmation, shows what it contains, and excludes document content. See the complete privacy policy.

Supported systems and license

The current portable preview targets 64-bit Windows 10 and Windows 11. Nettongia PDF Editor is open-source software; the repository contains the authoritative license, source code, build workflow, issue tracker and test history. Feedback and reproducible bug reports are welcome at support@nettongia.com or in GitHub Issues.
